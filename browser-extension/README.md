# freeweb-resolver status — расширение

Две вещи:

1. **Индикатор статуса.** Значок в панели браузера опрашивает
   `http://127.0.0.1:15380/_freeweb/status` раз в 30 секунд:
   - ✓ зелёный — резолвер и IPFS-нода отвечают
   - ! оранжевый — резолвер жив, IPFS-нода недоступна
   - ✕ красный — резолвер не отвечает

2. **Автоматический редирект на рабочий порт.** `.eth`-сайты по умолчанию
   идут на порт 443, где наш шлюз не слушает (он на `15443`, чтобы не
   требовать root — см. основной README про сброс привилегий). Расширение
   ловит именно эту неудачную попытку соединения (через
   `webNavigation.onErrorOccurred`) и молча перенаправляет вкладку на
   `https://имя.eth:15443/...` — то есть можно печатать `vitalik.eth` или
   `https://vitalik.eth` без ручного дописывания порта.

**Честно про один момент, который не проверил вживую** (нет доступа к
браузеру в этой сессии для реального теста): если набрать `vitalik.eth` в
адресной строке совсем без `https://`, Chrome может решить, что это не
адрес, а поисковый запрос, и вообще не попытается перейти по адресу — тогда
расширение ничего не увидит и редирект не сработает. С явным `https://`
в начале Chrome точно пытается перейти по адресу, и вот это должно работать
надёжно. Проверь оба варианта сам и дай знать, если первый не сработает —
это будет значить, что нужно доп. решение (например, через omnibox API).

## Установка (пока не в Chrome Web Store)

1. Открой `chrome://extensions` (работает и в Edge/Brave — тот же движок)
2. Включи **Developer mode** (переключатель справа сверху)
3. **Load unpacked** → выбери эту папку (`browser-extension/`)

Готово, значок появится в панели инструментов.
